# Lab 6: Compare the Groups

A standalone independent-samples t-test lab for GitHub Pages.

Place index.html, Lab6_Training_Data.csv, and .nojekyll in the publishing directory of your GitHub Pages repository. The index.html file is the homepage. No build step or dependencies are required.

The CSV download is also embedded in the HTML, so it works offline. Students record all responses in a Word document and upload that document to Canvas. The webpage does not collect or save answers.
